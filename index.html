Compiler Design

Code: PCC-CS501 3L/week · 3 Credits Compulsory Theory 25 CA + 70 Exam
Download Official MAKAUT PDF
Module 16 Hours

Lexical Analysis & Compiler Phases

Phases of a compiler, pass structure, lexical tokens, regular expressions to finite automata (NFA/DFA), transition diagrams, and LEX lexical analyzer generator.

Module 210 Hours

Syntax Analysis & Parsing

Context-Free Grammars, derivation trees, ambiguity. Top-Down LL(1) parsing, FIRST & FOLLOW sets. Bottom-Up LR parsing, Shift-Reduce, SLR(1), LALR(1), CLR(1) tables, YACC parser generator.

Module 35 Hours

Syntax Directed Translation

Syntax-directed definitions (SDD), synthesized and inherited attributes, dependency graphs, evaluation orders, translation schemes (SDT), and construction of syntax trees.

Module 44 Hours

Type Checking & Type Systems

Type systems, specification of a simple type checker, structural and nominal equivalence of type expressions, implicit & explicit type conversions.

Module 55 Hours

Run-Time Environments

Source language issues, activation trees, control stack, symbol tables, storage organization, activation records, static vs stack vs heap allocation strategies, parameter passing techniques.

Module 66 Hours

Intermediate Code & Optimization

Intermediate representations, Three-Address Code, quadruples, triples, indirect triples. Basic blocks, flow graphs, DAG representation, loop optimization, and peephole optimization.

Operating Systems

Code: PCC-CS502 3L/week · 3 Credits Compulsory Theory 25 CA + 70 Exam
Download Official MAKAUT PDF
Module 13 Hours

Introduction to Operating Systems

Generations of OS, OS services, system calls, OS architectures: monolithic, layered, microkernel, virtual machine concepts. Case study on UNIX and Windows.

Module 26 Hours

Processes & CPU Scheduling

Process concept, PCB, states. Threads & models. Schedulers, context switching. Algorithms: FCFS, SJF, SRTF, Priority, Round Robin, Multilevel Queue scheduling.

Module 36 Hours

Process Synchronization

Critical section problem, Peterson's solution, hardware synchronization, semaphores, mutexes, monitors. Classical problems: Bounded Buffer, Readers-Writers, Dining Philosophers.

Module 45 Hours

Deadlocks

Necessary conditions, Resource Allocation Graphs (RAG), deadlock prevention strategies, avoidance via Banker's algorithm (Safety & Request), detection and recovery.

Module 58 Hours

Memory Management & Virtual Memory

Contiguous allocation, external & internal fragmentation, paging, TLB hardware, segmentation. Virtual memory, demand paging, page replacement: FIFO, LRU, Optimal, Belady's anomaly, thrashing.

Module 66 Hours

File Systems & Disk Scheduling

File attributes, access methods, directory structures, UNIX Inode indexing. Disk structure, scheduling algorithms: FCFS, SSTF, SCAN, C-SCAN, LOOK, C-LOOK.

Object Oriented Programming

Code: PCC-CS503 3L/week · 3 Credits Compulsory Theory 25 CA + 70 Exam
Download Official MAKAUT PDF
Module 14 Hours

Object-Oriented Concepts

Classes, objects, members of a class, relationships, data abstraction, encapsulation, message passing, Java environment and JVM architecture.

Module 26 Hours

Classes, Methods & Constructors

Constructor overloading, copy constructors, 'this' keyword, static members, garbage collection mechanisms, finalize method, string manipulation and StringBuffer.

Module 37 Hours

Inheritance & Polymorphism

Superclasses and subclasses, 'super' keyword, method overriding, dynamic method dispatch (runtime polymorphism), abstract classes, final keyword, interfaces and multiple inheritance simulation.

Module 45 Hours

Packages & Exception Handling

Defining and importing packages, access protection. Exception types, try, catch, throw, throws, finally clauses, custom user-defined exception handling.

Module 56 Hours

Multithreaded Programming

Thread creation (Thread class vs Runnable), thread priorities, thread synchronization (synchronized methods and blocks), inter-thread communication (wait, notify, notifyAll), deadlocks.

Module 67 Hours

Generics & Java Collections

Generic classes and methods, wildcards. Collections Framework: List, Set, Map, ArrayList, LinkedList, HashSet, HashMap, Iterator, File I/O streams.

Software Engineering

Code: ESC501 3L/week · 3 Credits Engineering Science 25 CA + 70 Exam
Download Official MAKAUT PDF
Module 16 Hours

Software Process Models

Software engineering methodologies, SDLC, Waterfall model, Prototyping, Spiral model, Evolutionary models, Agile methodologies (Scrum, Sprint planning, User stories).

Module 25 Hours

Requirements Engineering

Functional and non-functional requirements, SRS document structure (IEEE standard), Data Flow Diagrams (DFD levels 0/1/2), Data Dictionary, UML use case and sequence diagrams.

Module 36 Hours

Design Principles & Modularity

Architectural design, modularity, functional independence, Cohesion types (coincidental to functional), Coupling types (content to data), Structured coding, information hiding.

Module 48 Hours

Software Testing Strategies

Verification and validation. Levels of testing: Unit, Integration (top-down, bottom-up), System, Acceptance. Black-box testing (Equivalence Partitioning, BVA). White-box testing (Basis Path, McCabe Cyclomatic Complexity).

Module 56 Hours

Project Management & Quality

Software project scheduling, staffing, Configuration Management (SCM), cost estimation (COCOMO models), Software quality assurance, SEI CMM levels, ISO 9000 certification.

Industrial Management

Code: HSMC-501 3L/week · 3 Credits Humanities & Social Sci 25 CA + 70 Exam
Download Official MAKAUT PDF
Module 14 Hours

Management Principles & Functions

Nature and concepts of management, management functions (planning, organizing, leading, controlling). Scientific management: Taylor's principles, Fayol's 14 administrative principles.

Module 26 Hours

Human Resource & Motivation

Organizational structures, delegation, decentralization. Motivation theories: Maslow's hierarchy, Herzberg's two-factor, McGregor's Theory X/Y. Leadership styles.

Module 38 Hours

Financial Management & Costing

Financial accounting, Balance Sheet, Profit & Loss statements, depreciation methods, cost elements, Break-Even Analysis (BEP), capital budgeting techniques.

Module 48 Hours

Production & Inventory Control

Types of production (Job, Batch, Mass). Inventory control models: Economic Order Quantity (EOQ), ABC analysis, VED analysis, Just-in-Time (JIT) production concepts.

Module 58 Hours

Project Networks & Quality

Network analysis: CPM and PERT, identifying critical paths, slack time calculation. Quality management: Total Quality Management (TQM), Six Sigma, ISO quality systems.

Artificial Intelligence

Code: PEC-IT501B 3L/week · 3 Credits Professional Elective 25 CA + 70 Exam
Download Official MAKAUT PDF
Module 13 Hours

AI Foundations & Agents

Turing test, definitions of AI. Intelligent agents: PEAS model (Performance, Environment, Actuators, Sensors), agent types (reactive, goal-based, utility-based).

Module 28 Hours

Heuristic Search Techniques

Uninformed search (BFS, DFS, Uniform Cost). Informed search: Greedy best-first, A* algorithm (admissibility and consistency), Hill climbing, Simulated Annealing.

Module 36 Hours

Adversarial Search & Games

Game playing, Minimax algorithm, Alpha-Beta pruning, evaluation functions. Constraint Satisfaction Problems (CSP): backtracking, arc consistency.

Module 48 Hours

Knowledge & Logic

Propositional logic, First-Order Logic (FOL), syntax and semantics, CNF conversion, Resolution refutation, forward and backward chaining, Unification algorithm.

Module 55 Hours

Probabilistic Reasoning

Uncertainty handling, Bayesian networks semantics, conditional probability tables, Dempster-Shafer theory, Fuzzy sets, membership functions, and fuzzy logic operations.

Module 66 Hours

Learning & NLP Foundations

Forms of learning: inductive learning, decision trees (ID3 algorithm). NLP introduction: syntactic and semantic analysis. Expert systems architecture and rule-based shells.

Assessment Protocol

MAKAUT Examination Question Paper Format

Every core semester subject follows the official 70-mark university final examination structure partitioned into Groups A, B, and C.

Group A
10 × 1 = 10 Marks
Short definitions, multiple choice questions, truth/false verifications, and core formula applications across all syllabus modules.
Group B
3 × 5 = 15 Marks
Medium analytical questions requiring clear diagrams, comparative tables, derivation steps, and concise technical explanations.
Group C
3 × 15 = 45 Marks
In-depth design problems, numerical implementations, multi-part algorithmic derivations, and architectural case studies.
