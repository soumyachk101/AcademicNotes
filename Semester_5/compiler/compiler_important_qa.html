Q5Explain the role of Symbol Table across all compiler phases.

Detailed 5-Mark Solution:

1. Core Compiler Pipeline: A compiler translates source code to machine code in 6 sequential phases, supported by the Symbol Table and Error Handler.

graph TD Source[Source Code] --> L[Lexical Analyzer] L --> S[Syntax Analyzer] S --> Sem[Semantic Analyzer] Sem --> I[Intermediate Code Generator] I --> O[Code Optimizer] O --> C[Code Generator] C --> Machine[Machine Code] Sym[(Symbol Table)] -.-> L Sym -.-> S Sym -.-> Sem Sym -.-> I Sym -.-> O Sym -.-> C
Figure: 6-Phase Compiler Architecture Pipeline & Flowchart

2. Compiler Phases Breakdown:

  1. Lexical Analyzer (Scanner): Reads character stream \(\rightarrow\) produces Token stream.
  2. Syntax Analyzer (Parser): Checks grammar rules \(\rightarrow\) produces Parse Tree / AST.
  3. Semantic Analyzer: Performs type checking and operator consistency checks.
  4. Intermediate Code Generator (ICG): Produces Three-Address Code (TAC) / Quadruples.
  5. Code Optimizer: Improves execution speed and memory footprint.
  6. Code Generator: Converts optimized ICG \(\rightarrow\) target assembly / machine code.

Q1a) Construct Canonical LR(1) items and CLR(1) Parsing Table for grammar: S ➔ A A A ➔ a A | b b) Trace the parsing of input string 'aabb$' showing stack, input buffer, and actions.

15-Mark Master Exam Solution:

Part (a) Computing FIRST and FOLLOW Sets & LL(1) Parsing Table:

Given Grammar: \(E \rightarrow T E', E' \rightarrow + T E' \mid \epsilon, T \rightarrow F T', T' \rightarrow * F T' \mid \epsilon, F \rightarrow ( E ) \mid \text{id}\)

  • 1. FIRST Sets:
    \(FIRST(F) = \{(, \text{id}\}\)
    \(FIRST(T') = \{*, \epsilon\}\)
    \(FIRST(T) = \{(, \text{id}\}\)
    \(FIRST(E') = \{+, \epsilon\}\)
    \(FIRST(E) = \{(, \text{id}\}\)
  • 2. FOLLOW Sets:
    \(FOLLOW(E) = \{\$, )\}\)
    \(FOLLOW(E') = FOLLOW(E) = \{\$, )\}\)
    \(FOLLOW(T) = FIRST(E') \setminus \{\epsilon\} \cup FOLLOW(E) = \{+, \$, )\}\)
    \(FOLLOW(T') = FOLLOW(T) = \{+, \$, )\}\)
    \(FOLLOW(F) = FIRST(T') \setminus \{\epsilon\} \cup FOLLOW(T) = \{*, +, \$, )\}\)

LL(1) Parsing Table: All entries are uniquely defined without multiple entries, proving the grammar is LL(1)!
