Q1Explain OSI 7 Layer Architecture with functions of each layer.

Detailed 5-Mark Solution:

1. Core Architecture: The ISO/OSI Reference Model partitions network communication into 7 distinct functional layers.

Figure: ISO/OSI 7-Layer Network Architecture Stack & Data Flow

2. Layer Summary:

  1. Physical Layer: Transmission of raw bitstreams over physical medium (Cable, Hub, Repeater).
  2. Data Link Layer: Framing, MAC addressing, Error Detection (CRC), Flow Control (Switch, Bridge).
  3. Network Layer: Logical IP addressing, Packet Routing, Forwarding (Router).
  4. Transport Layer: End-to-end reliability, Port addressing, TCP/UDP Segmenting.
  5. Session Layer: Dialog control, Session checkpointing and recovery.
  6. Presentation Layer: Data format conversion, Encryption, Compression (SSL/TLS).
  7. Application Layer: Network services interface for user applications (HTTP, DNS, SMTP).

Figure: Cyclic Redundancy Check (CRC) Error Detection Pipeline

2. Algorithmic Steps:

  • Step 1: Append r zero bits to data stream M.
  • Step 2: Divide appended string by generator polynomial G(x) using XOR division.
  • Step 3: Append remainder R to M to form transmitted codeword T.

Q21Explain TCP 3-Way Handshake connection establishment.

Detailed 5-Mark Solution:

1. Connection Establishment: TCP uses a 3-Way Handshake to synchronize sequence numbers and establish a reliable bi-directional connection.

Figure: TCP 3-Way Handshake Connection & Termination Protocol

2. Handshake Protocol Sequence:

  • SYN (Client → Server): Client sends SYN segment with initial sequence number ISN = x.
  • SYN-ACK (Server → Client): Server responds with SYN-ACK, acknowledging ACK = x + 1 and setting its own sequence ISN = y.
  • ACK (Client → Server): Client sends ACK acknowledging ACK = y + 1. Connection becomes ESTABLISHED.

15-Mark Master Exam Solution:

Part (a) Mathematical Step-by-Step CRC Calculation:

Figure: Cyclic Redundancy Check (CRC) Error Detection Pipeline

Given Data bits M = 1101011011 (10 bits) and Generator polynomial G(x) = x^4 + x + 1 → 10011 (degree r = 4).

  • Step 1: Append r = 4 zeros to M: M' = 11010110110000.
  • Step 2 (Modulo-2 XOR Division): Divide 11010110110000 by 10011:
    11010 ⊕ 10011 = 01001 → bring down 1 → 10011 ⊕ 10011 = 00000
    Continuing long division yields 4-bit remainder R = 1110.
  • Step 3 (Transmitted Codeword): Transmitted frame T = M' \oplus R = 11010110111110.
  • Step 4 (Receiver Error Check): Receiver divides received codeword 11010110111110 by generator 10011. Remainder equals 0000, confirming zero error!
