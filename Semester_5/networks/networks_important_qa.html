Q1Explain OSI 7 Layer Architecture with functions of each layer.

Detailed 5-Mark Solution:

1. Core Architecture: The ISO/OSI Reference Model partitions network communication into 7 distinct functional layers.

graph TD 7[Application Layer] 6[Presentation Layer] 5[Session Layer] 4[Transport Layer] 3[Network Layer] 2[Data Link Layer] 1[Physical Layer] 7 --- 6 --- 5 --- 4 --- 3 --- 2 --- 1
Figure: ISO/OSI 7-Layer Network Architecture Stack & Data Flow

2. Layer Summary:

  1. Physical Layer: Transmission of raw bitstreams over physical medium (Cable, Hub, Repeater).
  2. Data Link Layer: Framing, MAC addressing, Error Detection (CRC), Flow Control (Switch, Bridge).
  3. Network Layer: Logical IP addressing, Packet Routing, Forwarding (Router).
  4. Transport Layer: End-to-end reliability, Port addressing, TCP/UDP Segmenting.
  5. Session Layer: Dialog control, Session checkpointing and recovery.
  6. Presentation Layer: Data format conversion, Encryption, Compression (SSL/TLS).
  7. Application Layer: Network services interface for user applications (HTTP, DNS, SMTP).

Q5Explain Error Detection using Cyclic Redundancy Check (CRC).

Detailed 5-Mark Solution:

1. Core Definition & Mechanism: CRC (Cyclic Redundancy Check) operates on polynomial modulo-2 XOR arithmetic.

graph TD Data[Data Stream] --> Div[Modulo-2 Division by Generator G] Div --> Remainder[Remainder R] Data --> Append[Transmitted Codeword T = Data + R] Remainder --> Append
Figure: Cyclic Redundancy Check (CRC) Error Detection Pipeline

2. Algorithmic Steps:

  • Step 1: Append \(r\) zero bits to data stream \(M\).
  • Step 2: Divide appended string by generator polynomial \(G(x)\) using XOR division.
  • Step 3: Append remainder \(R\) to \(M\) to form transmitted codeword \(T\).

Q21Explain TCP 3-Way Handshake connection establishment.

Detailed 5-Mark Solution:

1. Connection Establishment: TCP uses a 3-Way Handshake to synchronize sequence numbers and establish a reliable bi-directional connection.

sequenceDiagram participant Client participant Server Client->>Server: 1. SYN (seq=x) Server->>Client: 2. SYN-ACK (seq=y, ack=x+1) Client->>Server: 3. ACK (seq=x+1, ack=y+1)
Figure: TCP 3-Way Handshake Connection & Termination Protocol

2. Handshake Protocol Sequence:

  • SYN (Client \(\rightarrow\) Server): Client sends SYN segment with initial sequence number \(ISN = x\).
  • SYN-ACK (Server \(\rightarrow\) Client): Server responds with SYN-ACK, acknowledging \(ACK = x + 1\) and setting its own sequence \(ISN = y\).
  • ACK (Client \(\rightarrow\) Server): Client sends ACK acknowledging \(ACK = y + 1\). Connection becomes ESTABLISHED.

Group C — Long / Numerical Questions (15 Marks Each)

Q1a) Data bits = 1101011011, Generator polynomial G(x) = x^4 + x + 1 (10011). Calculate CRC checksum and transmitted frame. b) Explain Sliding Window Protocols efficiency: Stop-and-Wait vs Go-Back-N vs Selective Repeat.

15-Mark Master Exam Solution:

Part (a) Mathematical Step-by-Step CRC Calculation:

graph TD Data[Data Stream] --> Div[Modulo-2 Division by Generator G] Div --> Remainder[Remainder R] Data --> Append[Transmitted Codeword T = Data + R] Remainder --> Append
Figure: Cyclic Redundancy Check (CRC) Error Detection Pipeline

Given Data bits \(M = 1101011011\) (10 bits) and Generator polynomial \(G(x) = x^4 + x + 1 \rightarrow 10011\) (degree \(r = 4\)).

  • Step 1: Append \(r = 4\) zeros to \(M\): \(M' = 11010110110000\).
  • Step 2 (Modulo-2 XOR Division): Divide \(11010110110000\) by \(10011\):
    \(11010 \oplus 10011 = 01001\) \(\rightarrow\) bring down 1 \(\rightarrow\) \(10011 \oplus 10011 = 00000\)
    Continuing long division yields 4-bit remainder \(R = 1110\).
  • Step 3 (Transmitted Codeword): Transmitted frame \(T = M' \oplus R = 11010110111110\).
  • Step 4 (Receiver Error Check): Receiver divides received codeword \(11010110111110\) by generator \(10011\). Remainder equals \(0000\), confirming zero error!
Q2a) An IP block 192.168.1.0/24 is divided into 4 equal subnets. 1. Subnet mask. 2. Network address, Broadcast address, Usable Host IP range for each subnet. b) Explain Classless Inter-Domain Routing (CIDR) advantages.

15-Mark Master Exam Solution:

Part (a) IP Subnetting Numerical Derivation:

Given IP Block: \(192.168.1.0/24\) to be divided into 4 equal subnets.

  • 1. Subnet Bits (s): \(2^s = 4 \rightarrow s = 2\) bits. New Prefix Length = \(24 + 2 = 26\) (\(/26\)).
  • 2. Subnet Mask: \(255.255.255.192\) (Binary: \(11111111.11111111.11111111.11000000\)).
  • 3. Block Size: \(256 / 4 = 64\) IP addresses per subnet. Usable hosts per subnet = \(64 - 2 = 62\).

Subnet 0\(192.168.1.0/26\)\(192.168.1.1 \ndash 192.168.1.62\)\(192.168.1.63\)
Subnet 1\(192.168.1.64/26\)\(192.168.1.65 \ndash 192.168.1.126\)\(192.168.1.127\)
Subnet 2\(192.168.1.128/26\)\(192.168.1.129 \ndash 192.168.1.190\)\(192.168.1.191\)
