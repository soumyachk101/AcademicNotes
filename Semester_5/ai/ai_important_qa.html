Q4Explain A* Search Algorithm and g(n) + h(n) evaluation function.

Detailed 5-Mark Solution:

1. Core Definition & Evaluation Function: A* Search is an informed heuristic search algorithm evaluating nodes using:
f(n) = g(n) + h(n)
where g(n) is exact cost from start node to n, and h(n) is estimated cost from n to goal.

Figure: A* Search Graph Expansion & Heuristic Evaluation

2. Conditions for Optimality:

  • Admissibility: h(n) ≤ h*(n) (heuristic never overestimates actual minimal cost to goal).
  • Consistency: h(n) ≤ c(n, a, n') + h(n') (monotonic heuristic constraint).

Q11Explain Alpha-Beta Pruning rules with an example game tree.

Detailed 5-Mark Solution:

1. Core Definition & Mechanism: Alpha-Beta Pruning is an optimization technique for the minimax game tree algorithm that prunes subtrees when α ≥ β.

Figure: Alpha-Beta Pruning Minimax Game Tree Execution

2. Pruning Conditions:

  • Alpha (α): The highest-value choice found so far at any choice point along the path for MAX.
  • Beta (β): The lowest-value choice found so far at any choice point along the path for MIN.
  • Cut-off Rule: Stop searching below any MIN node if its beta value becomes less than or equal to the alpha value of any MAX ancestor (α ≥ β).

  1. Man(Marcus)
