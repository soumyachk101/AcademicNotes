Artificial Intelligence

Artificial Intelligence (AI) is the branch of computer science that aims to create systems capable of performing tasks that typically require human intelligence. This subject covers intelligent agent design, problem-solving through search, knowledge representation, machine learning fundamentals, and modern AI applications. Master these concepts thoroughly as they form the foundation for advanced AI and ML coursework.

Introduction to AI & Intelligent Agents

What is AI, history, Turing test, agent types, PEAS framework

What is Artificial Intelligence?

Definition: AI is the simulation of human intelligence processes by computer systems, including learning, reasoning, and self-correction. John McCarthy coined the term in 1956 at the Dartmouth Conference.

Brief History of AI:

  • 1950s: Turing Test proposed by Alan Turing; Dartmouth Conference (1956) — birth of AI
  • 1960s: Early optimism; first AI programs (ELIZA, SHRDLU)
  • 1970s: Expert systems emerge; first AI winter due to over-promising
  • 1980s: Expert systems boom; PROLOG, LISP popular
  • 1990s: Machine learning gains ground; Deep Blue beats Kasparov (1997)
  • 2000s: Big data era; recommender systems, NLP advances
  • 2010s: Deep learning revolution; AlexNet (2012), AlphaGo (2016)
  • 2020s: Large Language Models (LLMs), generative AI, ChatGPT (2022)

Turing Test (1950): Proposed by Alan Turing in his paper "Computing Machinery and Intelligence." A human evaluator engages in natural language conversations with a human and a machine. If the evaluator cannot reliably tell which is which (≥30% success rate), the machine is said to have passed the test. It tests behavioral equivalence rather than true understanding.

Weak AI (Narrow AI) vs Strong AI (General AI):

  • Weak/Narrow AI: Designed for specific tasks (e.g., Siri, Alexa, chess engines, face recognition). This is what exists today.
  • Strong/Artificial General Intelligence (AGI): A machine with human-like general intelligence — can understand, learn, and apply knowledge across any domain. Does not yet exist.
  • Super AI: Hypothetical AI that surpasses human intelligence across all domains.

Intelligent Agents

Agent: An entity that perceives its environment through sensors and acts upon that environment through actuators.

Environment: Everything the agent interacts with or that affects the agent's perceptions and actions.

PEAS Framework: A structured way to describe an agent by specifying:

  • P — Performance measure: How success is judged (e.g., accuracy, speed, safety)
  • E — Environment: The world the agent operates in
  • A — Actuators: How the agent acts on the environment
  • S — Sensors: How the agent perceives the environment

Example — Self-Driving Car:
Performance: Safe, efficient travel from A to B.
Environment: Roads, traffic, pedestrians, weather.
Actuators: Steering, acceleration, braking, signals.
Sensors: Cameras, LiDAR, GPS, radar, odometry.

Types of Agents (based on rationality):

  • Simple Reflex Agent: Acts only on current percept, ignores history. Uses condition-action rules (if-then). Example: Thermostat.
  • Model-Based Reflex Agent: Maintains internal state (partial world model). Useful when environment is partially observable. Example: Robot with a map.
  • Goal-Based Agent: Acts to achieve a specific goal. Requires search and planning. Example: Navigation system.
  • Utility-Based Agent: Maximizes a utility function measuring "happiness." Chooses actions that lead to best expected outcomes. Example: Investment advisor AI.
  • Learning Agent: Can improve performance over time by learning from experience. Has a learning element, critic, performance element, and problem generator. Example: Recommendation engines.
Types of AI (by Capability):
1. Reactive Machines — No memory; react to current input only (e.g., IBM Deep Blue).
2. Limited Memory — Use past data for decisions (e.g., self-driving cars, LLMs).
3. Theory of Mind — Understand emotions, beliefs, thoughts of others (future AI).
4. Self-Aware — Conscious, self-aware AI (hypothetical).

What is the Turing Test?
The Turing Test is a test of a machine's ability to exhibit intelligent behavior equivalent to that of a human. Proposed by Alan Turing in 1950, it involves a human evaluator engaging in natural language conversations with both a human and a machine. If the evaluator cannot reliably distinguish the machine from the human (typically judged by ≥30% correct identification), the machine is said to have passed the test.

Define AI in your own words.
Artificial Intelligence is the field of computer science dedicated to creating systems that can perform tasks requiring human-like intelligence — such as learning from experience, understanding natural language, recognizing patterns, solving problems, and making decisions. AI systems range from narrow task-specific programs (like recommendation engines) to the theoretical goal of general artificial intelligence.
5 Marks
Explain different types of AI agents with examples.

1. Simple Reflex Agent: The most basic type. It acts only on the current percept using condition-action rules (if-then logic). It has no memory of past states and no concept of goals. Example: A thermostat that turns the heater on when temperature drops below 18°C and off when it rises above 22°C.

2. Model-Based Reflex Agent: Maintains an internal state (partial world model) representing aspects of the environment that cannot be directly perceived. This allows better decision-making in partially observable environments. Example: A mobile robot that maintains an internal map of the room and tracks its own position.

3. Goal-Based Agent: Has explicit goals and chooses actions that achieve those goals. Uses search and planning to determine the best sequence of actions. More flexible than reflex agents but may be less efficient. Example: A GPS navigation system that plans the shortest route to a destination.

4. Utility-Based Agent: Goes beyond goal-based agents by using a utility function that maps states to a measure of "happiness" or desirability. This allows rational decisions when goals are conflicting or when there are multiple ways to achieve the same goal. Example: An AI investment advisor that maximizes expected returns while minimizing risk.

5. Learning Agent: Can improve its performance over time through learning. It has four components: (a) Learning element — makes improvements, (b) Critic — evaluates performance, (c) Performance element — selects actions, (d) Problem generator — suggests new experiences. Example: Netflix's recommendation engine that improves suggestions based on user watch history.

5 Marks
What is the PEAS framework? Describe it with an example.

The PEAS framework is a structured approach to describe and analyze intelligent agents by specifying four key components: Performance measure, Environment, Actuators, and Sensors.

Components explained:

  • Performance Measure: The criterion by which the agent's success is judged. It defines what is "good" for the agent. Examples: accuracy, speed, safety, profitability.
  • Environment: The external world the agent operates in. It can be fully or partially observable, deterministic or stochastic, episodic or sequential, static or dynamic, discrete or continuous, and single-agent or multi-agent.
  • Actuators: The mechanisms through which the agent acts on the environment. Examples: motors, speakers, display screens, robotic arms.
  • Sensors: The mechanisms through which the agent perceives the environment. Examples: cameras, microphones, GPS, touch sensors.

Example — Online Medical Diagnosis Assistant:

  • P (Performance): Minimize misdiagnosis rate; maximize speed of diagnosis; ensure patient safety.
  • E (Environment): Patients, medical records, symptoms database, diagnostic literature.
  • A (Actuators): Display diagnosis results, flag urgent cases, send alerts to doctors, recommend treatments.
  • S (Sensors): Input forms for symptoms, lab report data, patient history, doctor feedback on diagnosis accuracy.

Search & Problem Solving

Problem formulation, uninformed search, informed search, heuristic search

Problem Solving Agents

Problem Formulation: The process of defining a problem in terms of:

  • Initial State: Where the agent starts
  • Actions: Possible actions the agent can take (defined by an action function ACTIONS(s))
  • Transition Model: Describes the result of each action (RESULT(s, a))
  • Goal Test: Determines if the current state is a goal state
  • Path Cost: A numeric cost assigned to each path (used for optimality)

Search Strategies: Algorithms that explore the state space to find a solution path from the initial state to a goal state. Search strategies can be evaluated along these dimensions:

  • Completeness: Does it always find a solution if one exists?
  • Optimality: Does it find the optimal (least-cost) solution?
  • Time Complexity: How long does it take to find a solution?
  • Space Complexity: How much memory does it need?

Search Algorithms

Uninformed (Blind) Search: No additional information about the problem beyond the definition.

1. Breadth-First Search (BFS): Explores all nodes at depth d before moving to depth d+1. Uses a FIFO queue. Guaranteed complete and optimal for uniform-cost problems. Time and space complexity: O(b^d), where b = branching factor, d = depth.

2. Depth-First Search (DFS): Explores as far as possible along each branch before backtracking. Uses a LIFO stack. Not guaranteed to find optimal solution. Complete only for finite state spaces. Time complexity: O(b^m), space: O(b*m), where m = max depth. Much more memory-efficient than BFS.

3. Uniform Cost Search (UCS): Expands the node with the lowest path cost g(n). BFS is a special case of UCS where all step costs are equal. Complete and optimal for positive step costs. Time complexity: O(b^(C/epsilon)), where C* is the optimal cost.

Informed (Heuristic) Search: Uses domain-specific knowledge (heuristic) to guide the search more efficiently toward the goal.

4. Greedy Best-First Search: Expands the node closest to the goal according to a heuristic h(n). Fast but not optimal or complete. Can get stuck in dead ends.

5. A* Search: Uses evaluation function f(n) = g(n) + h(n), where g(n) is the actual cost from start to node n, and h(n) is the estimated cost from n to the goal. Optimal and complete if h(n) is admissible and consistent.

Heuristic Search

Heuristic Function h(n): An estimate of the cheapest path from node n to a goal node. A good heuristic guides the search efficiently without sacrificing optimality.

Admissible Heuristic: A heuristic that never overestimates the true cost to reach the goal. Formally: h(n) ≤ h*(n) for all n, where h* is the true cost. Admissibility guarantees A* optimality.

Monotonicity (Consistency): A heuristic h is consistent if for every node n and every successor n', the estimated cost of reaching the goal from n is ≤ the step cost from n to n' plus the estimated cost from n' to the goal. Formally: h(n) ≤ c(n, a, n') + h(n'). Monotonicity implies admissibility.

Local Search Algorithms: Operate on a single current node and move to neighboring nodes:

  • Hill Climbing: Greedily moves to the neighbor with the best value. Can get stuck in local maxima, plateaus, or ridges. Variants: stochastic hill climbing, first-choice hill climbing, random-restart hill climbing, simulated annealing.
  • Simulated Annealing: Allows occasional "bad" moves (downhill steps) to escape local maxima, with probability decreasing over time. Inspired by metallurgical annealing. Temperature T starts high and gradually decreases.
  • Genetic Algorithms: Population-based search inspired by evolution. Maintains a population of candidate solutions. Applies selection (fitness-based), crossover (combining solutions), and mutation (random changes) to evolve better solutions over generations.
BFS vs DFS vs A* — Quick Comparison:
Property BFS DFS A*
Complete? Yes (finite branching) No (infinite paths) Yes (finite branching, positive costs)
Optimal? Yes (uniform cost) No Yes (with admissible heuristic)
Time O(b^d) O(b^m) Exponential in worst case
Space O(b^d) O(b·m) O(b^d) worst case
1 Mark
What is a heuristic function?
A heuristic function h(n) is an estimate of the minimum cost from the current node n to the nearest goal node. It is a "rule of thumb" used in informed search algorithms to guide the search more efficiently toward the solution. A good heuristic should be admissible (never overestimate the true cost) and should be as close to the true cost as possible for efficiency.
1 Mark
Difference between BFS and DFS.
BFS (Breadth-First Search): Explores all nodes at the current depth level before moving to the next level. Uses a FIFO queue. Guaranteed to find the shortest path in unweighted graphs. Higher memory usage as it stores all frontier nodes. Complete and optimal for unit-cost problems.

DFS (Depth-First Search): Explores as deep as possible along each branch before backtracking. Uses a LIFO stack. Does not guarantee shortest path. Lower memory usage (stores only one path at a time). Can get stuck in infinite loops. Not optimal but often faster to find a solution.
5 Marks
Explain A* search algorithm with example.

A* Search Algorithm is an informed search algorithm that finds the least-cost path from an initial node to a goal node. It combines the advantages of UCS (optimality) and Greedy Best-First (efficiency) by using the evaluation function:

f(n) = g(n) + h(n)

where g(n) = actual cost from start to node n, and h(n) = estimated cost from n to the goal.

Algorithm Steps:

  1. Initialize the OPEN list with the start node: f(start) = g(start) + h(start) = 0 + h(start).
  2. While OPEN is not empty:
    • Remove the node with lowest f-value from OPEN.
    • If it is the goal, reconstruct and return the path.
    • Expand the node: generate all successors.
    • For each successor: compute g, h, f values. Add to OPEN if not already there, or update if a better path is found.
  3. If OPEN is empty, no path exists.

Example: Consider finding the shortest path from node A to node G in the following graph:

A → B (cost 2), A → C (cost 4), B → D (cost 3), B → E (cost 1), C → F (cost 5), D → G (cost 6), E → G (cost 8)

Heuristic estimates h: h(A)=6, h(B)=4, h(C)=5, h(D)=3, h(E)=7, h(F)=2, h(G)=0

StepNodeg(n)h(n)f(n)
1A066
2B (via A)246
3C (via A)459
4E (via B)3710
5D (via B)538
6G (via D)11011

A* explores nodes in order of f-value: A → B → D → G, finding the optimal path A→B→D→G with total cost 11.

5 Marks
Compare and contrast different search strategies.

Uninformed vs Informed Search:

Uninformed search strategies (BFS, DFS, UCS) have no knowledge about the problem beyond its definition. They systematically explore the state space without any guidance toward the goal. Informed search strategies (Greedy Best-First, A*) use heuristic information to guide the search more efficiently.

BFS vs DFS: BFS explores level by level (guarantees shortest path in unweighted graphs) but uses more memory (O(b^d)). DFS goes deep first (lower memory O(b·m)) but does not guarantee optimality. BFS is complete for finite branching factors; DFS is not.

UCS vs A*: UCS expands based on actual path cost g(n). It guarantees optimality but can be inefficient because it doesn't use any estimate of remaining cost. A* uses f(n) = g(n) + h(n), combining actual cost with heuristic estimate. With an admissible heuristic, A* is both optimal and generally more efficient than UCS.

Greedy Best-First vs A*: Greedy uses only h(n), making it very fast but neither optimal nor complete. A* uses g(n) + h(n), making it optimal (with admissible heuristic) and complete, though potentially slower in practice due to exploring more nodes.

Local Search (Hill Climbing, Simulated Annealing, Genetic Algorithms): These are used for optimization problems where the path doesn't matter. They work on large or continuous spaces. Hill climbing is fast but prone to local maxima. Simulated annealing escapes local optima with probabilistic acceptance. Genetic algorithms maintain a population and use evolutionary operators, suitable for very large search spaces.

Problem: Find the shortest path from city S (Start) to city G (Goal) using A* search.

  • S —B— (cost 1)

  • h(S) = 8, h(A) = 6, h(B) = 5, h(C) = 4, h(D) = 3, h(E) = 2, h(G) = 0
