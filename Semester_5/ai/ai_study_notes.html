Unit 1 · Introduction to AI & Intelligent Agents

Foundations · PEAS · Agent types
U1Core concepts
Definition

Artificial Intelligence (AI) is the branch of computer science devoted to creating systems that perform tasks which, when done by humans, require intelligence — learning, reasoning, problem solving, perception and language understanding (Rich & Knight, 2010).

AI is conventionally grouped into four categories by capability:

  • Reactive Machines — respond only to current percepts; no memory. Example: Deep Blue.
  • Limited Memory — use recent percepts plus stored knowledge. Example: self-driving cars.
  • Theory of Mind — understand that others have beliefs and intentions (still research).
  • Self-Aware AI — hypothetical systems aware of their own internal state.

1MU1 / Q1
Define Artificial Intelligence.

The branch of computer science that aims to build systems capable of performing tasks that ordinarily require human intelligence — reasoning, learning, perception and decision making.

1MU1 / Q2
What is an intelligent agent?

Anything that perceives its environment through sensors and acts upon it through actuators to achieve a goal. Formally: Agent = Architecture + Agent Program.

1MU1 / Q3
What does PEAS stand for?

Performance measure, Environment, Actuators, Sensors. It is a standard descriptor for an agent’s task environment.

1MU1 / Q4
Define rational agent.

An agent that selects the action that maximises its expected performance measure, given its percept history and built-in knowledge.

1MU1 / Q5
Distinguish between agent function and agent program.

The agent function maps the entire percept history to an action f : P* → A (abstract mapping). The agent program is the concrete implementation that runs on the physical agent.

1MU1 / Q6
What is autonomy in an agent?

The agent’s ability to act on its own percepts rather than relying on prior knowledge supplied by the designer. More autonomous agents learn from experience.

1MU1 / Q7
Name two properties of task environments.

Fully / partially observable; deterministic / stochastic; episodic / sequential; static / dynamic; discrete / continuous; single-agent / multi-agent.

1MU1 / Q8
Give an example of a multi-agent environment.

Football — teammates coordinate to score while opponents counter; partial observability, stochastic and dynamic.

5MU1 / Q4
Describe the structure of a learning agent.

A learning agent has four conceptual components:

  • Performance element — chooses actions given percepts (the “body”).
  • Critic — compares actual outcomes to a fixed standard of performance.
  • Learning element — modifies the performance element using feedback from the critic.
  • Problem generator — suggests exploratory actions that lead to informative new experiences.

The interaction closes the loop — experience shapes future behaviour.

Unit 2 · Problem Solving & Search

Uninformed · Informed · Heuristics
Definition

Search is the process of exploring a problem’s state space to find a sequence of actions that leads from an initial state to a goal state.

A search problem is defined by:

  • The initial state.
  • A successor function S(x) = { (action, state) }.
  • A goal test.
  • A path cost function g(n).

1-mark Questions

1 mark
1MU2 / Q1
What is state space?

The graph whose nodes are all reachable configurations of the world and whose edges are the actions that move between them.

1MU2 / Q2
Differentiate between uninformed and informed search.

Uninformed (blind) search uses only the problem definition. Informed search additionally uses a heuristic h(n) to estimate the cost from n to the goal.

1MU2 / Q3
What is a heuristic function?

A function h(n) that estimates the cheapest cost from node n to a goal. It is problem-specific and admissible if it never overestimates.

1MU2 / Q4
Name two uninformed search strategies.

Breadth-First Search (BFS), Depth-First Search (DFS), Uniform-Cost Search, Depth-Limited Search, Iterative Deepening DFS (IDDFS).

1MU2 / Q5
Define admissibility of a heuristic.

A heuristic is admissible if h(n) ≤ h*(n) for every node n — it never overestimates the true cost to a goal.

1MU2 / Q6
What is iterative deepening DFS?

It performs DFS with depth limits 0, 1, 2, … until the goal is found. Combines BFS’s completeness with DFS’s low memory.

1MU2 / Q7
Define consistent (monotone) heuristic.

A heuristic h is consistent if h(n) ≤ cost(n, n') + h(n') for every successor n’ of n. Consistent implies admissible.

1MU2 / Q8
What is the 8-puzzle?

A sliding-tile puzzle on a 3×3 board with one blank. State space ≈ 9!/2 = 181,440 reachable states.

5MU2 / Q2
Explain Hill Climbing. What are its limitations?

Hill climbing is a local search that repeatedly moves to the neighbour with the highest value (steepest ascent). It uses no memory of past states beyond the current one.

Variants:

  • Steepest-ascent hill climbing — picks the best neighbour.
  • First-choice hill climbing — picks the first improving neighbour (faster when many neighbours).
  • Random-restart hill climbing — tries multiple random starts and keeps the best.

Limitations:

  • Local maxima — stuck at a peak that is not the global best.
  • Ridges — sequence of local maxima makes greedy ascent hard.
  • Plateaux — flat regions where no neighbour is better; sideways move may help but risks loops.
5MU2 / Q3
Describe the A* algorithm. When is A* optimal?

A* expands nodes in order of f(n) = g(n) + h(n), where g is the cost so far and h is the heuristic estimate to the goal. It combines the completeness of UCS with the heuristic guidance of greedy search.

A* is optimal if:

  • h is admissible (never overestimates), and
  • the cost of any node is bounded below by a positive constant (no zero-cost steps).

A* is optimally efficient: among all optimal algorithms, no other expands fewer nodes than A*.

5MU2 / Q4
What are local search and metaheuristic algorithms? List any three.

Local search algorithms keep only the current state (constant memory) and try to improve it. They are suitable for problems where the path is irrelevant (e.g., 8-queens, scheduling, VLSI layout).

  • Hill climbing — greedy ascent.
  • Simulated annealing — accepts worse moves with probability e−ΔE/T; T is gradually cooled.
  • Local beam search — keeps k states; can be stochastic (randomised restarts shared).
  • Genetic algorithms — population-based; selection, crossover, mutation.

15MU2 / Q3
Discuss constraint satisfaction problems (CSP) with backtracking and forward checking.

A CSP is defined by a set of variables X, domains D for each variable, and a set of constraints C. The goal is to find an assignment that satisfies every constraint. Examples include map colouring, the 8-queens problem, and Sudoku.

Backtracking search assigns variables one at a time and backtracks when a constraint is violated. Improvements include:

  • Variable ordering (MRV) — choose the variable with the fewest remaining values.
  • Degree heuristic — tie-break by most constraints on remaining variables.
  • Least-constraining-value — try values that rule out the fewest choices for neighbours first.

Forward checking keeps track of remaining legal values for unassigned variables. When a value is assigned to X, prune the domains of neighbours that conflict with it. If any domain becomes empty, backtrack immediately.

Arc consistency (AC-3) further strengthens this: a variable Xi is arc-consistent with Xj if every value in Di has some value in Dj that satisfies the binary constraint. AC-3 is run after each assignment and propagates pruning through the constraint graph.

Unit 3 · Adversarial Search & Games

· α-β pruning
Definition

Game playing is a special kind of search in which we plan against an adversary. The opponent introduces uncertainty about future states because we do not control its moves.

A game is defined by:

  • Initial position, legal moves in each position.
  • A terminal test — is the game over?
  • A utility (payoff) function — outcome value at terminal positions.

1-mark Questions

1 mark
1MU3 / Q1
What is the algorithm?

A recursive algorithm that chooses the move with the best worst-case outcome, assuming the opponent plays optimally. The MAX player picks the action with maximum utility; the MIN player picks the minimum.

1MU3 / Q2
What is alpha-beta pruning?

An optimisation of that prunes branches that cannot influence the final decision. α = best value MAX can guarantee; β = best value MIN can guarantee.

1MU3 / Q3
Define zero-sum game.

A game in which the total payoff is constant; one player’s gain is the other’s loss. Chess, tic-tac-toe and Go are zero-sum.

1MU3 / Q4
What is a utility function in a game?

The function that assigns a numerical score to each terminal state from MAX’s perspective. For chess typically win=+1, loss=-1, draw=0.

1MU3 / Q5
State the optimal branching factor of alpha-beta with perfect ordering.

b√d instead of bd — you can search twice as deep with the same resources.

5-mark Questions

5 marks
5MU3 / Q1
Explain the algorithm with pseudocode.
Algorithm function (state, depth, player) returns an action if TERMINAL-TEST(state): return utility(state) if player = MAX: v ← -∞ for each a in ACTIONS(state): v ← max(v, MIN-VALUE(RESULT(state, a), depth+1, MIN)) return v else (player = MIN): v ← +∞ for each a in ACTIONS(state): v ← min(v, MAX-VALUE(RESULT(state, a), depth+1, MAX)) return v

The recursion backs up values from leaves to the root. MAX picks the action with maximum backed-up value; MIN picks the minimum.

5MU3 / Q2
How does alpha-beta pruning work? Show the cutoff condition.

α-β tracks two bounds while traversing the tree:

  • α — the best value that MAX can guarantee so far on the path to the root.
  • β — the best value that MIN can guarantee so far on the path to the root.

Cutoff condition: prune the branch when α ≥ β. The returned value is still correct because the pruned subtree cannot improve on what MAX/MIN already has.

5MU3 / Q3
Why is node ordering important in alpha-beta search?

With perfect ordering α-β examines roughly bd/2 nodes — effective branching factor √b. With random ordering it is b3d/4. In the worst case (reverse ordering) it is no better than plain . Hence, in practice, we use iterative deepening plus move ordering (best move first from previous iteration or from a transposition table) to maximise pruning.

Unit 4 · Knowledge Representation & Reasoning

Logic · Propositional · FOL
Definition

Knowledge representation is the study of how to encode knowledge about the world in a form that a computer can use to solve complex tasks such as diagnosis, planning and natural-language understanding.

1-mark Questions

1 mark
1MU4 / Q1
What is a proposition?

A declarative statement that is either true or false (e.g., “The sky is blue”).

1MU4 / Q2
Define First-Order Logic (FOL).

A representation language that extends propositional logic with objects, relations, functions, variables, and quantifiers (∀, ∃).

1MU4 / Q3
What is the difference between ∀ and ∃?

∀x means “for all x” (universal). ∃x means “there exists some x” (existential).

1MU4 / Q4
State Modus Ponens.

If P → Q and P, then Q. The fundamental inference rule of propositional logic.

1MU4 / Q5
Define a semantic network.

A directed graph whose nodes represent objects or concepts and whose edges represent binary relations between them. Useful for representing hierarchical categories.

1MU4 / Q6
What is a frame in knowledge representation?

A data structure for representing a stereotyped situation (e.g., a “lecture” frame has slots speaker, topic, time). Frames inherit from more general frames.

1MU4 / Q7
What is inference?

The process of deriving new sentences (conclusions) from existing sentences (premises) using logical rules.

1MU4 / Q8
Differentiate sound and complete inference.

Sound — only derives entailed sentences. Complete — derives every sentence that is entailed.

Frame — a structured object with slots (attributes) and fillers (values). Frames support default reasoning: a slot may have a default value used unless overridden (e.g., a bird normally flies).

15-mark Questions

15 marks
15MU4 / Q1PYQ [2022]
Explain resolution in first-order logic. Demonstrate with a simple example.

Resolution is a sound and complete inference rule for FOL once the knowledge base is in conjunctive normal form (CNF). It unifies complementary literals from two clauses and yields their resolvent.

  1. Convert every sentence to CNF — eliminate implications, move negations inward using De Morgan and quantifier duality, standardise variables apart, drop universal quantifiers, distribute ∨ over ∧.
  2. Convert to clausal form and rename so no variable appears in both clauses.
  3. Apply unification to find substitutions that make complementary literals identical.
  4. Resolve: from clauses (A ∨ ¬B) and (B ∨ C) infer (A ∨ C).

Example:

KB: ¬Cat(x) ∨ Mammal(x); Cat(Felix); ∀x Mammal(x) → Pet(x); ∀x Pet(x) → Warm(x).

  • CNF: 1) ¬Cat(x) ∨ Mammal(x); 2) Cat(Felix); 3) ¬Mammal(x) ∨ Pet(x); 4) ¬Pet(x) ∨ Warm(x).
  • Resolve 1 & 2 with {x/Felix} → Mammal(Felix).
  • Resolve with 3 → Pet(Felix).
  • Resolve with 4 → Warm(Felix). Goal proved.
15MU4 / Q2
Discuss the Wumpus World as a knowledge representation problem.

The Wumpus World is a 4×4 grid cave. The agent must find gold while avoiding pits (B) and the Wumpus (W). Squares adjacent to a pit emit breeze; adjacent to the Wumpus emit stench; the gold square glitters.

Each cell is represented by propositions Pi,j (pit), Wi,j (wumpus), Bi,j (breeze), Si,j (stench).

Sample axioms:

  • B1,1 ↔ = (P1,2 ∨ P2,1)
  • S1,1 ↔ = W1,2 ∨ W2,1
  • ¬P1,1, ¬W1,1, ¬P2,2 …

The agent uses logical inference to determine which squares are provably safe (no pit & no wumpus). The world illustrates how propositional reasoning can produce a complete plan from a small axiom set.

Unit 5 · Uncertainty, Fuzzy Logic & Expert Systems

Bayes · Rule-based systems
Definition

Uncertainty arises when an agent does not know the true state of the world. Probabilistic reasoning quantifies degrees of belief.

1-mark Questions

1 mark
1MU5 / Q1
State Bayes’ theorem.

P(A|B) = P(B|A) · P(A) / P(B) — relates posterior to prior and likelihood.

1MU5 / Q2
What is a prior probability?

The probability of a hypothesis before observing any evidence, written P(H).

1MU5 / Q3
Define fuzzy logic.

A generalisation of Boolean logic in which truth values range in [0, 1] instead of {0, 1}. Useful for vague concepts like “warm” or “tall”.

1MU5 / Q4
What is a membership function?

In fuzzy sets, a function μ(x) ∈ [0,1] that gives the degree to which x belongs to a fuzzy set.

1MU5 / Q5
Define an expert system.

A computer system that emulates the decision-making of a human expert in a specific domain, using a knowledge base and an inference engine.

1MU5 / Q6
Name one expert system shell.

CLIPS, Jess, Prolog, EMYCIN, MYCIN (early medical system).

5MU5 / Q2
Explain Bayesian inference with a small example.

Problem: A disease affects 1% of the population. A test has 99% true-positive and 5% false-positive rates. A patient tests positive. What is the probability they have the disease?

  • P(D) = 0.01, P(¬D) = 0.99
  • P(+|D) = 0.99, P(+|¬D) = 0.05
  • P(+) = P(+|D) P(D) + P(+|¬D) P(¬D) = 0.99·0.01 + 0.05·0.99 = 0.0594
  • P(D|+) = 0.99 · 0.01 / 0.0594 ≈ 0.167

Even with a positive test, the probability of disease is only ~17% because the disease is rare.

5MU5 / Q3
Describe fuzzy inference with defuzzification.
  1. Fuzzify the crisp inputs using membership functions.
  2. Apply rules (IF–THEN with fuzzy antecedents → fuzzy consequents).
  3. Aggregate the consequent fuzzy sets.
  4. Defuzzify to obtain a crisp output. Common method: centroid of the aggregated set.

Example: an air conditioner control uses fuzzy rules — IF temp is high AND humidity is high THEN fan speed is high.

15-mark Questions

15 marks
15MU5 / Q1PYQ [2021]
Discuss the Bayesian network approach to reasoning under uncertainty. Show inference in the “Earthquake” network.

A Bayesian network is a directed acyclic graph (DAG) where each node represents a random variable and each edge a direct probabilistic dependence. Each node has a conditional probability table P(Xi | Parents(Xi)).

The joint distribution factors as:

P(X1, X2, …, Xn) = ∏i=1..n P(Xi | Parents(Xi))

Earthquake example (Russell & Norvig):

  • Variables: Burglary (B), Earthquake (E), Alarm (A), JohnCalls (J), MaryCalls (M).
  • Edges: B → A; E → A; A → J; A → M.

Exact inference enumerates all assignments consistent with evidence. For P(A | j, m, ¬b, ¬e):

  1. Sum over A: P(A|j,m,¬b,¬e) = α P(j|A) P(m|A) P(A|¬b,¬e).
  2. P(j|A) P(m|A) P(A|¬b,¬e) for A = true: 0.90 · 0.70 · 0.001 = 0.00063.
  3. For A = false: 0.05 · 0.01 · 0.999 = 0.0004995.
  4. After normalisation: P(A=j,m|¬b,¬e) ≈ 0.558.

Approximate inference (variational methods, MCMC, Gibbs sampling) scales to large networks.

  • IF temperature is hot AND humidity is high THEN fan speed is very fast.

Unit 6 · Machine Learning Basics

Supervised · Unsupervised · Neural nets
Definition

Machine learning is the study of algorithms that improve their behaviour at a task by observing data, without being explicitly programmed for every case (Mitchell, 1997).

1-mark Questions

1 mark
1MU6 / Q1
Differentiate supervised and unsupervised learning.

Supervised learns from labelled input-output pairs (e.g., classification, regression). Unsupervised learns patterns from unlabelled data (e.g., clustering, dimensionality reduction).

1MU6 / Q2
What is overfitting?

When a model fits the training data so closely that it captures noise and fails to generalise to unseen test data.

1MU6 / Q3
State the perceptron learning rule.

wi ← wi + α (t − o) xi, where t is target, o is output, and α is the learning rate.

1MU6 / Q4
Define a neural network.

A computational model loosely inspired by biological neurons, organised in layers: input, hidden, and output. Each neuron applies a weighted sum followed by a non-linear activation.

1MU6 / Q5
What is decision tree learning?

A supervised method that learns a tree where each internal node tests an attribute, each branch is an outcome, and each leaf is a class label. ID3, C4.5 and CART are classic algorithms.

5-mark Questions

5 marks
5MU6 / Q1
Explain the k-Nearest Neighbour algorithm.

k-NN is an instance-based lazy learner. For a new instance x:

  1. Compute the distance to every training example (usually Euclidean).
  2. Take the k closest examples.
  3. Output the majority class (classification) or the mean value (regression).

Pros: no training, simple. Cons: slow at query time, sensitive to irrelevant features and to the choice of k.

5MU6 / Q2
Describe the Naive Bayes classifier.

Naive Bayes assumes features are conditionally independent given the class. By Bayes' theorem:

P(c|x) ∝ P(c) ∏i P(xi | c)

Predict the class with the maximum posterior. Parameters are estimated by counting occurrences in the training data (with Laplace smoothing to avoid zero probabilities). It is surprisingly strong for text classification.

15MU6 / Q1
Discuss artificial neural networks: the perceptron, multi-layer feed-forward, and backpropagation.

Perceptron (Rosenblatt 1958). A linear threshold unit computes o = step(w · x + b). Learning rule: wi ← wi + α (t − o) xi. Perceptrons can represent only linearly separable functions (XOR is the famous counter-example).

Figure 6.1 — Multi-layer feed-forward neural network

Multi-layer feed-forward networks. One or more hidden layers with non-linear activations (sigmoid, tanh, ReLU) overcome the XOR limit.

Backpropagation. Computes the gradient of the loss L with respect to every weight using the chain rule. Two passes:

  1. Forward pass — compute activations.
  2. Backward pass — propagate the error from output to input, computing δi = (ti − oi) f'(neti).

Update rule: wij ← wij + α δi oj. Stochastic gradient descent, momentum, Adam, and batch normalisation are modern refinements.

Unit 7 · NLP, Modern AI & Generative Models

Definition

Natural language processing (NLP) is the branch of AI concerned with the interaction between computers and human (natural) languages, in both written and spoken form.

1-mark Questions

1 mark
1MU7 / Q1
What is tokenisation?

Splitting raw text into smaller units — words, sub-words or characters — for downstream processing.

1MU7 / Q2
Define stemming.

Reducing a word to its morphological root by chopping off suffixes (e.g., “running” → “run”). Crude but fast.

1MU7 / Q3
What is a large language model (LLM)?

A transformer neural network trained on massive text corpora to predict the next token, capable of generating fluent text, answering questions and reasoning.

1MU7 / Q4
Define self-attention.

A mechanism that computes each token’s representation as a weighted sum of all other tokens in the sequence, with weights learned from the data.

1MU7 / Q5
What is prompt engineering?

Crafting the input to an LLM to elicit useful, accurate outputs. Techniques include few-shot examples, chain-of-thought and role assignment.

5-mark Questions

5 marks
5MU7 / Q1
Explain the stages of natural language processing.
  1. Morphological analysis — identify parts of words (stems, affixes).
  2. Syntactic analysis (parsing) — build a parse tree (constituency or dependency).
  3. Semantic analysis — extract meaning; word-sense disambiguation.
  4. Discourse analysis — resolve pronouns, sentence relations.
  5. Pragmatic analysis — infer speaker intent.
5MU7 / Q2
Describe the transformer architecture in brief.

The transformer (Vaswani et al., 2017) replaces recurrence and convolution with self-attention. An encoder stack and a decoder stack are made of identical blocks containing:

  • Multi-head self-attention — captures different relationships in parallel subspaces.
  • Position-wise feed-forward network — two linear layers with ReLU.
  • Residual connections and layer normalisation.

Positional encodings inject order information. The decoder additionally attends to the encoder output (cross-attention).

5MU7 / Q3
What is RAG (Retrieval-Augmented Generation)?

RAG grounds an LLM’s answer in external documents. At query time:

  1. The query is embedded and used to retrieve relevant passages from a vector store.
  2. The passages are appended to the prompt as context.
  3. The LLM produces an answer that cites the supplied passages.

RAG reduces hallucinations, keeps knowledge fresh without retraining, and is the dominant pattern for production chatbots.

Discuss the evolution and impact of Generative AI (2020–2025).

Timeline of generative AI:

  • 2017 — Transformer architecture proposed.
  • 2018 — BERT (Google) and GPT-1 (OpenAI) introduce pre-training + fine-tuning.
  • 2020 — GPT-3 (175B parameters) demonstrates few-shot learning.
  • 2021 — DALL-E and Stable Diffusion popularise diffusion-based image generation.
  • 2022 — ChatGPT reaches 100M users in two months — fastest consumer product adoption ever.
  • 2023 — GPT-4, Claude 3, Gemini, Llama 2 — multimodal models enter the mainstream.
  • 2024 — Agentic AI (Claude 3.5 Sonnet, OpenAI o1) — models that plan and use tools.
  • 2025 — Reasoning-focused and open-source models (Llama 4, DeepSeek-R1, Claude 4.5 family) continue to close the gap.

Key concepts:

  • Foundation models — large pre-trained backbones adapted to many tasks.
  • RLHF / RLAIF — aligning outputs with human preferences.
  • Tool use and agents — LLMs that call APIs and execute multi-step plans.
  • Multimodality — jointly processing text, images, audio, video.

Impact and risks: productivity boost in software and knowledge work; concerns about hallucination, copyright, bias, deepfakes, energy use and labour displacement. Safety research (Constitutional AI, red-teaming) and policy (EU AI Act, India’s Digital India AI framework) are evolving in parallel.

Previous Year Questions & Exam Tips

PYQs · High-yield areas

Selected Previous Year Questions (MAKAUT style)

2MPYQ [2023]
Define AI and name its branches.

AI is the simulation of human intelligence in machines. Branches: Machine Learning, NLP, Computer Vision, Robotics, Expert Systems, Planning, Speech Recognition.

5MPYQ [2023]
Explain BFS and DFS. State their time and space complexities.

BFS explores level by level using a FIFO queue — complete, optimal for uniform step cost; complexity O(bd) time and space.

DFS explores depth-first using a LIFO stack — not complete in infinite spaces, not optimal; complexity O(bm) time, O(bm) space.

5MPYQ [2022]
Differentiate between informed and uninformed search. Give one example of each.

Uninformed — uses only the problem definition. Example: BFS, DFS, UCS. Informed — uses heuristic h(n). Example: A*, greedy best-first.

5MPYQ [2021]
Write a short note on the Tic-Tac-Toe problem as an AI application.

Tic-tac-toe is a zero-sum game with at most 9! = 362,880 game-tree paths. With perfect play from both sides it always ends in a draw. with alpha-beta pruning easily finds optimal moves; it is the canonical illustration of adversarial search.

15MPYQ [2023]
Explain A* algorithm. Discuss admissibility, monotonicity and optimality of A* with examples.

A* uses f(n) = g(n) + h(n). A* is admissible (finds an optimal solution) if h is admissible. A* is optimally efficient (no other optimal algorithm expands fewer nodes). Monotonicity (h(n) ≤ cost(n, n') + h(n')) implies that the first time a node is expanded its f value is the optimal one. With consistent h, A* also has the “no reopening” property.

15MPYQ [2022]
Explain unification and resolution in predicate logic with an example.

Unification finds a substitution θ that makes two logical expressions identical. The Unify algorithm (Robinson) is used. Resolution is the corresponding inference rule. Example: from ∀x (Cat(x) → Animal(x)) and Cat(Felix), resolve to Animal(Felix).

Exam Tips & Strategy

Strategy

1. Cover the full syllabus — MAKAUT paper has Group A (30 × 1 mark), Group B (any 5 × 5 marks = 25), Group C (any 3 × 15 marks = 45).

2. Define-then-explain — for every 5-mark and 15-mark answer, begin with a crisp definition and a diagram where applicable.

3. Draw diagrams for search trees, neural networks and Bayesian networks — they earn easy marks.

4. Show the algorithm in pseudocode for any search / learning / game algorithm — it demonstrates understanding.

5. End with a real-world example or application — examiners reward context.

High-yield topics

Algorithms that appear almost every year:

  • A* with heuristic, admissibility proof — very common.
  • with alpha-beta pruning on a small tree — almost guaranteed.
  • Resolution in FOL with Wumpus / family example.
  • Bayesian network inference for the Earthquake network.
  • Comparison table between search algorithms.
Common mistakes to avoid
  • Confusing completeness (will find a solution if one exists) with optimality (will find the best one).
  • Forgetting the conditioning event when applying Bayes’ theorem.
  • Stating that perceptrons can solve XOR — they cannot, unless you add a hidden layer.
  • Writing α-β values without explaining when the cutoff fires.
  • Leaving out the CNF steps when answering resolution questions.
