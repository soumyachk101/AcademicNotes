Q21Define Cyclomatic Complexity.

Ans: Cyclomatic Complexity V(G) is a quantitative software metric measuring the number of linearly independent paths through a program's control flow graph. Formula: \(V(G) = E - N + 2P\) (Edges \(E\), Nodes \(N\), Connected Components \(P\)) or \(V(G) = D + 1\) where \(D\) is decision points.

Q22What is McCabe's Cyclomatic Complexity formula?

Ans: Cyclomatic Complexity V(G) is a quantitative software metric measuring the number of linearly independent paths through a program's control flow graph. Formula: \(V(G) = E - N + 2P\) (Edges \(E\), Nodes \(N\), Connected Components \(P\)) or \(V(G) = D + 1\) where \(D\) is decision points.
