Classes & Objects

Foundation of OOP — classes, objects, access specifiers, member functions

Class vs Object

A class is a user-defined data type that acts as a blueprint for creating objects. It encapsulates data members (variables) and member functions (methods) into a single unit. An object is an instance of a class — a real-world entity that occupies memory when created.

Key difference: A class is a logical entity (no memory allocated), while an object is a physical entity (memory allocated). Multiple objects can be created from a single class.

Data Members and Member Functions

Data members are variables declared inside a class that represent the properties/attributes of objects. Member functions are functions declared inside a class that define the behavior of objects.

Types of member functions:

  • Inline functions — defined inside class, expanded at compile time
  • Const member functions — cannot modify data members
  • Static member functions — belong to the class, not any object
  • Friend functions — non-member functions granted access to private members

Access Specifiers (public, private, protected)

Access specifiers control the visibility and accessibility of class members:

  • public — accessible from anywhere. Default for struct.
  • private — accessible only within the class. Default for class.
  • protected — accessible within the class and derived classes.

Encapsulation is achieved by making data members private and providing public getter/setter functions.

this Pointer and Friend Functions

The this pointer is a special pointer that points to the current object. It is passed implicitly to all non-static member functions. Used to differentiate between local variables and data members with the same name.

A friend function is a non-member function that is granted access to the private and protected members of a class. It is declared using the friend keyword. Friend functions are useful for operator overloading and when two classes need to share data.

Key Concept: The this pointer is an lvalue pointer, so it cannot be modified. It is implicitly passed as a hidden argument to all non-static member functions. For the object obj.func(), the call internally becomes func(&obj).

Constructors & Destructors

Special member functions — initialization and cleanup of objects

Default, Parameterized, and Copy Constructors

A constructor is a special member function automatically called when an object is created. It initializes data members.

  • Default constructor — takes no parameters. Initializes with default values.
  • Parameterized constructor — accepts parameters for initialization.
  • Copy constructor — creates a new object as a copy of an existing object. Called when: passing by value, returning by value, or explicit copy initialization.

Destructor and Dynamic Memory

A destructor is a special member function called automatically when an object goes out of scope or is deleted. It has the same name as the class prefixed with ~ and takes no parameters, returns nothing.

Destructors are essential when the class uses dynamic memory allocation (via new). The destructor must use delete to free that memory and prevent memory leaks. Destructors are called in reverse order of constructor calls.

Constructor Overloading and this Pointer Usage

Constructor overloading means having multiple constructors in a class with different parameter lists. The compiler chooses the appropriate one based on the arguments passed.

The this pointer is used in constructors (and other member functions) when parameter names shadow data member names:

Box(int l, int b) { this->length = l; // this->length refers to data member this->breadth = b; // l and b are parameters }
If a class uses dynamic memory, you must define: destructor, copy constructor, and assignment operator (Rule of Three). C++11 added move constructor and move assignment (Rule of Five).
1 Mark
What is a constructor?
A constructor is a special member function that is automatically invoked when an object of a class is created. It has the same name as the class, no return type (not even void), and is used to initialize data members to valid initial values.
1 Mark
What is a destructor?
A destructor is a special member function that is automatically called when an object goes out of scope or is explicitly deleted. It has the same name as the class prefixed with ~, takes no parameters, returns nothing, and is used to release resources like dynamically allocated memory.
5 Marks
Explain types of constructors with example.

1. Default Constructor: No parameters. Initializes with default values.

Student() { roll = 0; marks = 0.0; }

2. Parameterized Constructor: Accepts parameters to initialize with specific values.

Student(int r, float m) { roll = r; marks = m; }

3. Copy Constructor: Creates a copy of an existing object.

Student(const Student& s) { roll = s.roll; marks = s.marks; }

4. Move Constructor (C++11): Transfers resources from a temporary (rvalue) object, avoiding expensive deep copies.

5 Marks
What is a copy constructor? When is it called?

A copy constructor is a constructor that creates a new object by copying the data from an existing object of the same class. Its parameter must be a reference (usually const reference) to an object of the same class.

It is called automatically in these situations:

  • When an object is initialized from another object of the same type: Student s2 = s1;
  • When an object is passed by value to a function.
  • When a function returns an object by value.

Without a user-defined copy constructor, the compiler provides a shallow copy (bitwise copy), which can cause problems with pointers/dynamic memory.

15 Marks
Explain constructor overloading and copy constructor with suitable C++ program. Also explain when destructor is called.

Constructor overloading allows a class to have multiple constructors with different parameters. This gives flexibility in object creation.

Destructor is called automatically when: an object goes out of scope, a dynamically allocated object is deleted, or the program terminates. Destructors are called in reverse order of construction.

#include <iostream> using namespace std; class Array { int* arr; int size; public: // Default constructor Array() { size = 5; arr = new int[size]; cout << "Default ctor\n"; } // Parameterized constructor Array(int s) { size = s; arr = new int[s]; cout << "Param ctor\n"; } // Copy constructor Array(const Array& a) { size = a.size; arr = new int[size]; // deep copy for(int i=0; i<size; i++) arr[i] = a.arr[i]; cout << "Copy ctor\n"; } // Destructor ~Array() { delete[] arr; // free dynamic memory cout << "Destructor called\n"; } }; int main() { Array a1; // default ctor Array a2(10); // parameterized ctor Array a3 = a2; // copy ctor return 0; // destructors called in reverse: a3, a2, a1 }

Inheritance

Code reusability — deriving new classes from existing ones

What is Inheritance?

Inheritance is the mechanism by which a new class (derived/child class) acquires the properties and behaviors of an existing class (base/parent class). It promotes code reusability and establishes an "is-a" relationship between classes.

The derived class can add its own features while inheriting everything from the base class, except constructors, destructors, overloaded operators, and private members.

Types of Inheritance

1. Single: One base → one derived

2. Multilevel: A → B → C (chain of inheritance)

3. Hierarchical: One base → multiple derived classes

4. Multiple: One derived → multiple base classes

5. Hybrid: Combination of two or more types (e.g., hierarchical + multilevel)

Modes of Inheritance and Virtual Functions

Inheritance modes determine how base class members are inherited:

  • public inheritance: public→public, protected→protected
  • protected inheritance: public→protected, protected→protected
  • private inheritance: public→private, protected→private

Virtual functions enable runtime polymorphism. A virtual function in a base class ensures the correct overridden version is called based on the actual object type, not the pointer/reference type. Declared with virtual keyword.

Multiple Inheritance Ambiguity: When a derived class inherits from two base classes that have a function with the same name, the compiler cannot decide which to call. This is resolved using the scope resolution operator (Base1::func()) or virtual base class.
1 Mark
What is inheritance?
Inheritance is an OOP mechanism where a derived (child) class acquires the properties (data members) and behaviors (member functions) of a base (parent) class. It establishes an "is-a" relationship and promotes code reusability without rewriting existing code.
1 Mark
Types of inheritance.
The five types of inheritance in C++ are: Single (1 base → 1 derived), Multilevel (A→B→C), Hierarchical (1 base → multiple derived), Multiple (1 derived → multiple bases), and Hybrid (combination of two or more types).
5 Marks
Explain different types of inheritance with diagrams.

Single: class B : public A — B inherits from A.

Multilevel: class C : public B where B already inherits from A — C gets A's features through B.

Hierarchical: class B : public A and class C : public A — both B and C inherit from A.

Multiple: class C : public A, public B — C inherits from both A and B.

Hybrid: e.g., hierarchical + multilevel — A is base, B and C inherit from A, D inherits from B (combines multiple patterns).

5 Marks
What is a virtual function?
A virtual function is a base class function declared with the virtual keyword that can be overridden in derived classes. It enables runtime polymorphism — when called through a base class pointer/reference, the compiler determines the actual function to call at runtime based on the object's true type. The function must be redefined in the derived class with the same signature.
15 Marks
Explain single, multilevel and multiple inheritance with C++ programs. What are ambiguities in multiple inheritance and how are they resolved?

Single Inheritance Example:

class Animal { public: void eat() { cout<<"Eating\n"; } }; class Dog : public Animal { public: void bark() { cout<<"Barking\n"; } };

Multilevel Inheritance:

class A { public: void showA() {} }; class B : public A { public: void showB() {} }; class C : public B { public: void showC() {} }; // C inherits from B which inherits from A

Multiple Inheritance with Ambiguity:

class A { public: void show() { cout<<"A\n"; } }; class B { public: void show() { cout<<"B\n"; } }; class C : public A, public B { public: void display() { A::show(); // resolve: A's version B::show(); // resolve: B's version } };

Resolution using virtual base class:

class A { public: int val; }; class B : virtual public A {}; class C : virtual public A {}; class D : public B, public C {}; // D has only ONE copy of A (virtual base)

Polymorphism

Multiple forms — overloading, overriding, abstract classes

What is Polymorphism?

Polymorphism means "many forms." It allows objects of different classes to be treated as objects of a common base class, and the correct function is called based on the actual object type at runtime (or compile time for overloading).

Two types:

  • Compile-time polymorphism (static binding) — achieved through function overloading and operator overloading.
  • Runtime polymorphism (dynamic binding) — achieved through virtual functions and function overriding.

Function Overloading and Operator Overloading

Function overloading allows multiple functions with the same name but different parameter lists. The compiler distinguishes them by the number, type, or order of parameters.

Operator overloading allows redefining the behavior of operators (like +, ++, ==) for user-defined types. At least one operand must be a user-defined type. Implemented using a special member function or friend function.

Abstract Classes and Pure Virtual Functions

An abstract class is a class that cannot be instantiated. It contains at least one pure virtual function, declared as virtual returnType func() = 0;. Abstract classes serve as incomplete base classes — derived classes must override all pure virtual functions to become concrete (instantiable).

A pure virtual function has no implementation in the base class; it only declares the interface that derived classes must implement.

Key Difference: Function overloading happens at compile time with same function name, different parameters. Function overriding happens at runtime when a derived class redefines a base class virtual function with the same signature.
1 Mark
What is polymorphism?
Polymorphism is an OOP concept where a single entity (function name, operator, or object) can take multiple forms. In C++, it allows calling the appropriate function based on the context — at compile time (overloading) or runtime (overriding via virtual functions).
1 Mark
Function overloading vs overriding.

Overloading: Same function name, different parameters in the SAME class. Resolved at compile time. Example: add(int,int) and add(float,float).

Overriding: Same function signature in BASE and DERIVED classes. The derived version replaces the base version. Requires the base function to be virtual. Resolved at runtime.

5 Marks
Explain operator overloading with example.

Operator overloading allows operators to work with user-defined types. Example — overloading + for a Complex class:

class Complex { int real, imag; public: Complex(int r=0, int i=0) { real=r; imag=i; } // Overload + operator Complex operator+ (const Complex& c) { return Complex(real+c.real, imag+c.imag); } void show() { cout<<real<<"+"<<imag<<"i\n"; } }; int main() { Complex c1(3,4), c2(5,6), c3; c3 = c1 + c2; // uses operator+ c3.show(); // Output: 8+10i }
5 Marks
What is a pure virtual function?
A pure virtual function is a virtual function in an abstract class that has no implementation (only declaration) and is initialized to 0: virtual void draw() = 0;. Any class containing at least one pure virtual function becomes an abstract class and cannot be instantiated. Derived classes must override all pure virtual functions to become concrete classes. Pure virtual functions define an interface contract.

Explain compile-time and runtime polymorphism in detail. Write C++ programs demonstrating function overloading, operator overloading and virtual functions.

Compile-time polymorphism (static binding):

// Function Overloading class Math { public: int add(int a, int b) { return a+b; } int add(int a, int b, int c) { return a+b+c; } float add(float a, float b) { return a+b; } }; // Resolved at compile time based on parameters

Operator Overloading:

Exception Handling

Graceful error management — try, catch, throw, custom exceptions

What is Exception Handling?

Exception handling is a mechanism in C++ to handle runtime errors (exceptions) gracefully without crashing the program. It separates error-handling code from normal program logic.

Key keywords:

  • try — block that contains code that may throw an exception.
  • catch — block that handles the exception of a specific type.
  • throw — keyword used to signal (raise) an exception.

Catch Handlers and Stack Unwinding

Catch handlers catch exceptions of a specific type. You can have multiple catch blocks for different exception types, or a catch-all catch(...) block.

Stack unwinding is the process where the C++ runtime destroys all objects on the stack between the try block and the throw statement. As the stack unwinds, destructors are called for all local objects, ensuring proper cleanup.

Custom Exceptions and Exception Hierarchy

C++ provides a standard exception class hierarchy rooted at std::exception. Standard exceptions include bad_alloc, out_of_range, invalid_argument, etc.

You can create custom exception classes by inheriting from std::exception and overriding the what() method:

class NegativeNumber : public exception { public: const char* what() const throw() { return "Number cannot be negative!"; } };
Best Practice: Always catch exceptions by const reference (catch(const exception& e)) to avoid slicing. Use specific exception types before generic ones. The throw inside a catch block re-throws the same exception.
1 Mark
What is exception handling?
Exception handling is a C++ mechanism to manage runtime errors (exceptions) without terminating the program. It uses try, catch, and throw keywords to separate normal code from error-handling code, allowing graceful recovery from errors.
1 Mark
Keywords in exception handling.
The three main keywords are: try (defines a block where exceptions may occur), catch (defines a block that handles the exception), and throw (raises/signals an exception). Additional: throws (Java), but in C++, exception specification is deprecated in favor of noexcept.
5 Marks
Explain try, catch and throw with example.
#include <iostream> using namespace std; int main() { int a, b; cout << "Enter two numbers: "; cin >> a >> b; try { if(b == 0) throw "Division by zero!"; // throw string cout << "Result: " << a/b << endl; } catch(const char* msg) { cout << "Error: " << msg << endl; } catch(...) { cout << "Unknown error\n"; } return 0; }

The try block contains risky code. If an exception is thrown, execution jumps to the matching catch block. Multiple catch blocks can handle different exception types.

5 Marks
What is stack unwinding?
Stack unwinding is the process triggered when an exception is thrown. The C++ runtime walks back up the call stack, destroying all local objects (calling their destructors) until it reaches a matching catch block. This ensures proper resource cleanup (memory, file handles, locks). If no matching catch is found, std::terminate() is called, ending the program.
15 Marks
Explain exception handling mechanism in C++. Write a program that demonstrates custom exception class and multiple catch blocks.

C++ exception handling uses three keywords: try, catch, throw. When an exception occurs, the current function's stack is unwound, and control transfers to the nearest matching catch block. This separates error handling from main logic.

#include <iostream> #include <exception> using namespace std; // Custom exception class class AgeError : public exception { int age; public: AgeError(int a) : age(a) {} const char* what() const throw() { return "Age must be between 18 and 60!"; } int getAge() { return age; } }; void validateAge(int age) { if(age < 18 || age > 60) throw AgeError(age); cout << "Age valid: " << age << endl; } int main() { try { validateAge(15); // throws AgeError validateAge(25); // normal execution int x = 10, y = 0; if(y == 0) throw "Divide by zero"; } catch(const AgeError& e) { cout << "Custom Exception: " << e.what(); cout << " (entered: " << e.getAge() << ")\n"; } catch(const char* msg) { cout << "String Exception: " << msg << endl; } catch(...) { cout << "Some other exception occurred\n"; } return 0; }

Advanced OOP

Templates, STL, containers, iterators, file handling, RTTI

Templates — Function and Class

Templates enable writing generic code that works with any data type. They follow the principle of "write once, use with any type."

  • Function templates: A single function definition works with multiple types. template<typename T> T max(T a, T b) { return a>b?a:b; }
  • Class templates: An entire class is generic. template<class T> class Box { T data; };

STL — Containers, Iterators, Algorithms

The Standard Template Library (STL) is a collection of ready-to-use template classes for data structures and algorithms. It has three main components:

  • Containers: Store data — vector, list, deque, array, set, map, stack, queue.
  • Iterators: Objects that point to elements in containers, enabling traversal.
  • Algorithms: Functions like sort(), find(), reverse() that operate on containers via iterators.

File Handling, RTTI, Virtual Destructors

File handling with classes: Use fstream, ofstream, ifstream to read/write objects. Objects can be written to files using write() and read using read().

RTTI (Runtime Type Identification): C++ feature to determine the actual type of an object at runtime using typeid and dynamic_cast. Requires at least one virtual function in the class.

Virtual destructor: Declaring a destructor as virtual ensures the correct destructor chain is called when deleting objects through a base class pointer. Without it, only the base destructor runs, causing memory leaks.

STL Quick Reference: vector — dynamic array (random access). list — doubly linked list (fast insert/delete). map — key-value pairs (sorted, unique keys). set — unique sorted elements. stack — LIFO. queue — FIFO.
1 Mark
What is a template in C++?
A template is a feature in C++ that allows writing generic code. It enables functions or classes to operate with any data type without rewriting code for each type. Declared using the template keyword. The compiler generates the appropriate type-specific code at compile time (template instantiation).
1 Mark
What is STL?
STL (Standard Template Library) is a library of C++ template classes providing common data structures (containers) and algorithms. It includes containers (vector, list, map), iterators (pointers to container elements), and algorithms (sort, find, transform). It is part of the C++ standard library.
5 Marks
Explain function template with example.

A function template defines a generic function that works with any data type. The compiler generates specific versions for each used type.

template <typename T> T maximum(T a, T b) { return (a > b) ? a : b; } int main() { cout << maximum(int(3), int(7)); // T = int cout << maximum(double(3.5), double(2.1)); // T = double cout << maximum(char('a'), char('z')); // T = char }

The same function works for any type supporting the > operator. This avoids code duplication.

5 Marks
What are STL containers?

STL containers are template classes that store collections of objects. They are classified as:

Sequence containers: Maintain insertion order — vector (dynamic array, fast random access), list (doubly linked list, fast insert/delete), deque (double-ended queue).

Associative containers: Sorted by key — set (unique keys), multiset (duplicate keys), map (key-value pairs), multimap.

Derived containers: stack (LIFO), queue (FIFO), priority_queue.
